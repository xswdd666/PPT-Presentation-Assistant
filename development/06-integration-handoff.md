## 启动、外部依赖与迁移

详见根 [README](../README.md) 和 [.env.example](../.env.example)。

```powershell
pnpm install --frozen-lockfile
if (!(Test-Path .env)) { Copy-Item .env.example .env }
pnpm db:migrate
pnpm dev
```

- Node 24+、pnpm 11.22.0；浏览器测试使用 Edge。测试字体与 axe/像素比对依赖已锁定。
- 默认内置 Worker；独立模式设置 `EMBEDDED_WORKER=false`，运行 `pnpm dev:web`、`pnpm dev:worker`。
- 所有入口读取同一 `.env`；自定义 `DATA_DIR` 必须为同一绝对路径。
- `MODEL_API_KEY`、`MODEL_BASE_URL`、`MODEL_NAME` 配置真实模型。此次没有 `.env`，未进行在线模型调用。
- 本地数据库 schema v2 的空库/旧数据升级已验证；预留 PostgreSQL schema 不参与运行，未宣称 PostgreSQL 迁移通过。
- 停止所有写进程后备份整个数据目录；回滚同时恢复旧代码与升级前数据备份。仅在确认进程停止后处理遗留 `workspace.lock`，不自动抢锁。

在单独的 `artifacts/integration06/fresh-data` 运行 `db:migrate`、Worker `--once` 和真实 Web 入口均成功，`/health` 返回 `{"service":"web","status":"ok"}`。测试启动的 Web 已停止。

### 性能与一致性

一次 60 页本机浏览器验收记录：上传含解析约 **147 ms**，确定性分析约 **1081 ms**，首屏约 **205 ms**，定位末页约 **71 ms**。这是合成真实 PPTX、确定性模型、无高保真渲染的本机单次样本；不能证明真实模型的 15 页五分钟目标。SPEC 尚无确定的 60 页总时限。

修改 6 页文件中的一页后复用 **5 页**缓存；60 页仅排序后复用 **60 页**缓存。两个独立 OS 进程各提交 12 次事务，最终值 24；异常事务不改变磁盘快照。并发重复接受只生成一个版本，回复重试不重复追加用户消息。

日志只包含服务端生成的请求关联 ID、HTTP 状态和耗时；API 返回相同 `x-request-id`。测试验证日志不包含回复正文，未知错误不返回文件路径或 provider 异常。未进行完整安全渗透测试。
