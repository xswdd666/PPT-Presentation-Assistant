# 对话 1：PPTX 文档引擎

## 复制给新对话

你负责 `packages/pptx` 与 `tests/fixtures/pptx`。先阅读 spec、开发计划和阶段 A 契约。你不是唯一开发者，不要回滚他人改动，也不要修改前端、AI 或根配置。实现 contracts 端口对应的真实 PPTX 解析、渲染、受控修改、排序、隐藏/恢复、导出和布局检查。用真实 fixture 决定底层库；共享契约若不足，只做最小兼容变更并报告。完成后测试并提交独立 commit。

## 交付

- 原生文字、备注、元素边界、页面顺序和隐藏状态解析。
- 排序后仍稳定的 Slide ID / SlideElement ID。
- 页面渲染、中文字体替换元数据和页面内容哈希。
- 可编辑文字判定；基于元素 ID 与文本偏移的局部替换。
- 页面排序、隐藏、恢复和派生 PPTX 导出，不覆盖源文件。
- 溢出、遮挡或明显布局变化的页码级警告。
- 真实契约测试；覆盖 1/15/30/60 页与复杂元素样本。
- Aspose.Slides、Open XML/等价方案和渲染方案的选型 ADR。

## 不做

AI、评论 UI、上传 API、业务数据库；不声称支持未经真实样本验证的对象。

## 验收

fixture 修改、排序、隐藏、恢复后导出的 PPTX 可正常打开；未触碰元素不变；测试通过并记录已知限制。
