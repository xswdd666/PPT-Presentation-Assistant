## 每次独立评审收到的内容

1. 系统提示词：共同事实约束与该评审人的人设。
2. PPT 内容：项目背景、完整解析页面、逐页分析结果；所有评审人读取同一份材料。
3. 输出规则：只代表当前评审人；页面 ID 必须来自材料；每条初始评论 0–100 个显示字符；返回指定 JSON 格式。

每位评审人独立发起模型调用，不接收其他评审人的评论与历史。回复时还会传入该评审人在当前项目中的初始评论、带版本标记的全部双方回复，以及当前问题的评论锚点。模型本身无服务器端会话记忆，这些历史持久化在本地并在每次调用时重建。

初始评审与后续 AI 回复统一为 0–100 个显示字符，用户输入最多 4000 字。每位评审人一次处理一个回复，避免同一上下文并发错序。
